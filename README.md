Meet **SmartTrack**, a modern project management tool to track issues, run cycles (sprints), and manage product roadmaps without the chaos of managing the tool itself. 🧘‍♀️

## 🚀 Installation

Getting started with SmartTrack is simple. Choose the setup that works best for you:

- **Self-host SmartTrack**
  Prefer full control over your data and infrastructure? Install and run SmartTrack on your own servers. Follow our detailed deployment guides to get started.

## 🌟 Features

- **Work Items**
  Efficiently create and manage tasks with a robust rich text editor that supports file uploads. Enhance organization and tracking by adding sub-properties and referencing related issues.

- **Cycles**
  Maintain your team's momentum with Cycles. Track progress effortlessly using burn-down charts and other insightful tools.

- **Modules**
  Simplify complex projects by dividing them into smaller, manageable modules.

- **Views**
  Customize your workflow by creating filters to display only the most relevant issues. Save and share these views with ease.

- **Pages**
  Capture and organize ideas using SmartTrack Pages, complete with AI capabilities and a rich text editor. Format text, insert images, add hyperlinks, or convert your notes into actionable items.

- **Analytics**
  Access real-time insights across all your SmartTrack data. Visualize trends, remove blockers, and keep your projects moving forward.
